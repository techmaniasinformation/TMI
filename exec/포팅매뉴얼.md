# 2. 빌드 시 사용되는 환경 변수
환경 변수의 경우 jenkins에서 Credentials -> secret file로 관리한다.

### Backend
#### 1. 데이터베이스 (RDB) 관련
| 환경변수      | 설명 |
|---------------|------|
| RDB_URL       | DB 접속 URL (예: jdbc:mysql://host:port/dbname) |
| RDB_USER      | DB 접속 사용자 이름 |
| RDB_PASSWORD  | DB 비밀번호 |

#### 2. JWT 관련
| 환경변수      | 설명 |
|---------------|------|
| JWT_SECRET    | JWT 토큰 서명용 비밀키 |

#### 3. OAuth2 소셜 로그인 관련
| 환경변수                 | 설명 |
|--------------------------|------|
| KAKAO_CLIENT_ID          | 카카오 OAuth2 클라이언트 ID |
| KAKAO_CLIENT_SECRET      | 카카오 OAuth2 클라이언트 시크릿 |
| NAVER_CLIENT_ID          | 네이버 OAuth2 클라이언트 ID |
| NAVER_CLIENT_SECRET      | 네이버 OAuth2 클라이언트 시크릿 |
| GOOGLE_CLIENT_ID         | 구글 OAuth2 클라이언트 ID |
| GOOGLE_CLIENT_SECRET     | 구글 OAuth2 클라이언트 시크릿 |
| APP_OAUTH2_BASE_URL      | 애플리케이션 OAuth2 리다이렉트/콜백 기본 URL |

#### 4. 파일 업로드 관련
| 환경변수          | 설명 |
|------------------|------|
| FILE_UPLOAD_DIR   | 서버 로컬 파일 업로드 경로 |
| FILE_BASE_URL     | 업로드 파일 접근용 기본 URL |

#### 5. 외부 API Key
| 환경변수      | 설명 |
|---------------|------|
| GMS_KEY       | Google Maps Service 등 외부 서비스 API Key용 |
